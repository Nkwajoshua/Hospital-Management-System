# Hospital Management System

A simple web-based Hospital Management System built as an undergraduate Computer Science final-year project.

## Project Goal

Build a functional MVP that demonstrates one complete patient workflow:

**Patient Registration → Appointment → Doctor Consultation → Laboratory / Prescription → Pharmacy → Billing → Payment**

## Core Scope

- User authentication and staff roles
- Patient management
- Appointment management
- Consultation and medical records
- Laboratory management
- Pharmacy management
- Billing and payments

## Technology Stack

- Laravel 13
- PHP 8.3+
- Blade templates
- Bootstrap
- MySQL

## Scope Principle

This repository intentionally targets a working academic prototype rather than a production-grade hospital platform. Advanced features such as telemedicine, insurance claims, payroll, multi-hospital support, AI diagnosis, and complex inventory procurement are outside the MVP scope.
